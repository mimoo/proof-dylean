the lemma, from the library
theorem Trace.apply_Reachable_implies_Invariant
  [ReachableImpliesInvariant config] {p : ExecTrace → Prop} :
  (∀ trProof : ProofTrace, trProof.Invariant → p trProof.erase) →
  (∀ trExec : ExecTrace, trExec.Reachable config → p trExec)

Its instance argument is the induction over reachability, proved once: every protocol step and every attacker step preserves the invariant.

the lemma
theorem Trace.EventLoggedAt_imp_EventInv (ev) (i : Nat) (tr : ProofTrace) :
  tr.Invariant → tr.erase.EventLoggedAt ev i → EventInv.invariant (tr.prefix i) ev

Logging an event is only allowed when its invariant holds, so an event in an invariant trace carries its invariant at the prefix where it was logged.
